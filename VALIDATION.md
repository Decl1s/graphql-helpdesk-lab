# Что я действительно проверил

Дата: 28 октября 2026 года. Я проверяю учебный стенд на синтетическом наборе.

| Проверка | Мой фактический результат |
| --- | --- |
| Node API, локальный Linux, Node 24.22.0 | Я выполнил 8 проверок: все прошли |
| Реальный Bruno CLI 4.3.0 | Я выполнил 22 запроса и 83 декларативных Assert: все прошли |
| Отчёты | Я получил HTML, JSON и JUnit XML; сохраняю их локально в reports |
| npm audit после overrides и установки fflate | Я получил 0 известных уязвимостей в дереве из 530 пакетов, включая корневой |
| Контролируемый дефект прав | Я получил 2 красных запроса и 4 красных Assert; я отдельно подтвердил запрещённый IN_PROGRESS в 15 и падение Assert на null |

Я запускаю полный gate через `npm run check`: API, эталонная коллекция, проверка чувствительности коллекции к намеренному дефекту и ZIP по явному SOURCE_FILES. В Actions я использую ту же команду на Linux и Windows. Фактический результат удалённого запуска я смотрю в [Actions](https://github.com/Decl1s/graphql-helpdesk-lab/actions), а опубликованные артефакты — в [Releases](https://github.com/Decl1s/graphql-helpdesk-lab/releases). Я не называю наличие workflow доказательством его успешного исполнения.

Я не проверял окна Bruno Desktop на Linux, Windows или macOS. Я проверял файлы коллекции реальным CLI, но не выдаю это за ручной GUI-прогон. Я не проводил нагрузочные тесты, профессиональный аудит безопасности или проверку промышленной аутентификации. Я сохраняю состояние только в памяти, поэтому перезапуск сбрасывает изменения.

При первом запуске внутри ограниченной среды Node runner не смог выполнить локальный сценарий. Я повторил его с разрешённым временным loopback: проверки прошли. Я не изменял настройки системы, не ставил глобальные компоненты и не оставлял постоянный сервис.
