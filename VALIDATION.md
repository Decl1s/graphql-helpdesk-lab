# Что я проверил в объяснённой копии

| Проверка | Мой фактический результат |
| --- | --- |
| Сравнение исполняемой структуры JS | Я получил равенство 7 файлов после исключения комментариев и координат |
| Сравнение GraphQL-схемы | Я получил равенство контракта после разбора и канонической печати |
| Сравнение запросов | Я сверил все 22 файла без добавленных Docs: операции, заголовки, переменные и 83 Assert совпали |
| Сравнение зависимостей и workflow | Я получил побайтовое равенство package.json, lock, Local.bru и check.yml с основой |
| Чистая локальная установка | Я выполнил npm ci из ранее наполненного cache без install-скриптов |
| Node API в копии, Linux / Node 24.22.0 | Я выполнил 8 проверок: все прошли |
| Bruno CLI 4.3.0 в копии | Я выполнил 22 запроса и 83 Assert после добавления Docs: все прошли |
| Полный локальный gate | Я выполнил check: API, baseline и обнаружение заданного дефекта прошли; в режиме дефекта я получил 20/22 зелёных запроса и 79/83 Assert |

Я выполняю полный gate через npm run check: API, зелёную коллекцию, подтверждённое обнаружение дефекта и source-only ZIP. В режиме дефекта я ожидаю отказ проверок запроса 15; я дополнительно сверяю запрещённый IN_PROGRESS и конкретное падение Assert, а не только ненулевой exit code.

Удалённый прогон этой копии я смотрю в [Actions объяснённой ветки](https://github.com/Decl1s/graphql-helpdesk-lab/actions?query=branch%3Acodex%2Fexplained-edition). Я не приравниваю успех [CI исходной версии](https://github.com/Decl1s/graphql-helpdesk-lab/actions/runs/40726720072) к фактическому запуску новой ветки. В объяснённой ветке release job должен быть skipped: я сохраняю исходный стабильный релиз.

Я не проверял окна Bruno Desktop или VS Code на какой-либо ОС. Файлы коллекции я исполнял реальным CLI. Я не проводил нагрузочное тестирование или профессиональный аудит безопасности. Вымышленные данные я храню только в памяти; reset и перезапуск их сбрасывают.

Я оставил прежние версии зависимостей и overrides. Нулевой audit исходной версии относится к проверке 28.10.2026; текущий CI повторно запрашивает базу advisory. Я не считаю это обещанием отсутствия будущих уязвимостей.
