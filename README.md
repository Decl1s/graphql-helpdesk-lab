## Как я запускаю именно эту копию

Я устанавливаю [Node.js 24.22.0](https://nodejs.org/en/download), открываю терминал в этой папке рядом с package.json и выполняю:

```sh
npm ci --ignore-scripts --no-fund
npm start
```

Я устанавливаю [Bruno Desktop](https://www.usebruno.com/downloads), выбираю **Open Collection**, затем **папку collection именно этой копии**, окружение Local и запускаю весь набор последовательно. Я открываю Docs, чтобы читать объяснение текущего запроса. Я редактирую Query, Variables, Headers и таблицу Assert без написания JavaScript-тестов.

Для готового отчёта без установки Desktop я выполняю:

```sh
npm run demo
```

Я получаю `reports/regression.html` и открываю его двойным щелчком. Команда сама запускает временный сервер на свободном порту и завершает его. Я не должен перед этим выполнять npm start.

## Как я сохраняю полную версию

Я не удалял исходные сценарии, тесты или служебные скрипты. Я оставил зависимости и контракт версии 0.1.0. Через `npm run check` я выполняю API-проверки, эталонную коллекцию, обнаружение учебного дефекта и сборку source-only ZIP. Через `npm run package` я только пересобираю архив в dist; рядом я получаю SHA256SUMS.

Я публикую эту копию в отдельной [ветке codex/explained-edition](https://github.com/Decl1s/graphql-helpdesk-lab/tree/codex/explained-edition). Я могу скачать её через **Code → Download ZIP** этой ветки. Я сохраняю исходный main и стабильный релиз 0.1.0. Я не называю архив старого релиза архивом объяснённой копии.

Я использую только синтетические данные и адрес 127.0.0.1. Выбор роли заголовком — учебный переключатель. После reset или перезапуска я теряю изменения демо-набора. Фактические результаты проверки я фиксирую в VALIDATION.
