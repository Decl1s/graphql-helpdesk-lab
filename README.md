# Мой GraphQL Helpdesk Lab

Я собрал небольшой **учебный проект для QA с минимумом кода**. Я проверяю API службы поддержки в Bruno: читаю обращения, создаю новое, меняю статус сотрудником и проверяю запреты. Я редактирую запросы, переменные и таблицу Assert; JavaScript для основных упражнений мне не нужен.

**GraphQL — язык запросов и способ устройства API, а Bruno — инструмент, которым я его тестирую.**

## Как я начинаю

Я устанавливаю [Node.js 24.22.0](https://nodejs.org/en/download) и бесплатный [Bruno Desktop](https://www.usebruno.com/downloads). Я скачиваю [архив исходников](https://github.com/Decl1s/graphql-helpdesk-lab/releases/latest), распаковываю его и открываю терминал в папке с `package.json`.

```sh
npm ci --ignore-scripts --no-fund
npm start
```

Я получаю адрес `http://127.0.0.1:8767/graphql`. Я оставляю терминал открытым, в Bruno выбираю **Open Collection**, указываю папку `collection`, выбираю окружение **Local** и запускаю коллекцию **по порядку**, начиная с `00` и `01`. Я ожидаю **22 успешных запроса и 83 успешные проверки**. Я останавливаю сервер через `Ctrl+C`.

Я использую только вымышленные обращения. Перезапуск или `01-reset` удаляет мои изменения в демо-наборе. Этот стенд я не публикую в интернете: выбор роли заголовком — учебная имитация, а не настоящая аутентификация.

## Как я получаю отчёт одной командой

```sh
npm run demo
```

Я автоматически запускаю отдельный временный сервер на свободном локальном порту, выполняю ту же коллекцию и останавливаю его. Я открываю `reports/regression.html` двойным щелчком; рядом сохраняю JSON и JUnit XML. Для этого режима мне не требуется заранее запускать `npm start` или устанавливать Bruno Desktop. Я не публикую отчёты с локальными путями.

```sh
npm test
npm run check
npm run package
```

Я использую `test` для 8 дополнительных проверок стенда. Через `check` я выполняю API-проверки, зелёную коллекцию, проверяю обнаружение намеренного дефекта и собираю ZIP исходников. Во время `check` я **ожидаю красный промежуточный отчёт** `training-bug`; весь `check` завершается успешно, только если дефект обнаружен по смыслу, а не из-за сетевого сбоя. В `dist` я получаю архив и `SHA256SUMS`.

## Как я меняю проект под себя

Сначала я меняю `body:graphql:vars` и строки `assert` в копии запроса. Для нового окружения я копирую `collection/environments/Local.bru`. Контракт полей я читаю в `src/schema.graphql`, правила — в `src/app.js`. Если я изменяю правила продукта, я одновременно обновляю ожидаемый результат в тест-плане и коллекции. Основной маршрут я подробно описал в [GUIDE.md](GUIDE.md).

Я сделал учебное портфолио, а не промышленную систему поддержки. Я не заявляю проверку реального бизнеса, нагрузочную устойчивость или готовую защиту публичного сервиса. Я храню результаты фактических запусков и непроверенные части отдельно в [VALIDATION.md](VALIDATION.md).
